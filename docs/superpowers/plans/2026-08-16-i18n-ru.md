# RU/EN Localization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить русскую локаль с переключателем языка, сохранив английскую версию дефолтной и неизменной.

**Architecture:** Инварианты (id, годы, иконки, URL, логотипы, проценты, CSS-позиции) выносятся в `src/i18n/structure.tsx`; текст живёт в по-локальных `.tsx`-словарях под общим интерфейсом `Dictionary`. Полнота перевода гарантируется типами: словари объявлены как `Record<RoadmapId, …>`, поэтому пропущенный ключ валит сборку. Роутинг — встроенный `i18n` Next.js с префиксом `/ru`.

**Tech Stack:** Next.js 16 (Pages Router), React 18, TypeScript 5, styled-components 5, `next/font/local`

**Spec:** `docs/superpowers/specs/2026-08-16-i18n-ru-design.md`

## Global Constraints

- **Тестового раннера в проекте нет.** Скрипта `test` в `package.json` не существует, jest не сконфигурирован. Цикл проверки каждой задачи — `npx tsc --noEmit`, затем `npm run build`, затем ручной прогон в браузере. Не добавлять тестовый фреймворк: спека сознательно опирается на типы как на механизм проверки.
- **Базовое состояние:** `npx tsc --noEmit` на старте проходит без ошибок. Любая ошибка типа после изменения — ваша.
- **Английский текст переносится дословно**, включая существующие грамматические ошибки, лишние пробелы и опечатку `Posgress`. Не исправлять: это отдельная задача вне рамок плана.
- **Тон русских текстов:** обращение к читателю на «вы», деловой регистр.
- **Локали:** `en` (дефолтная, без префикса), `ru` (префикс `/ru`). Автоопределение языка выключено.
- **Не трогать:** `src/Components/CV_NO_DESIGN/`, `src/Pages/Main/articles.tsx`, `src/Components/MindMap/`, `botRougue/`, `ton.js`, `src/shared/CV.pdf`, артефакты CRA (`src/App.tsx`, `src/index.tsx`, `build/`, `src/index.css`).

Сейчас там захардкожено `<Html lang="ru">` на полностью английском сайте. Заменить содержимое файла целиком:

```tsx
import Document, { Html, Head, Main, NextScript, DocumentContext } from 'next/document'
import { ServerStyleSheet } from 'styled-components'

type MyDocumentProps = { locale: string }

export default class MyDocument extends Document<MyDocumentProps> {
  static async getInitialProps(ctx: DocumentContext) {
    const sheet = new ServerStyleSheet()
    const originalRenderPage = ctx.renderPage

    try {
      ctx.renderPage = () =>
        originalRenderPage({
          enhanceApp: (App) => (props) => sheet.collectStyles(<App {...props} />),
        })

      const initialProps = await Document.getInitialProps(ctx)
      return {
        ...initialProps,
        locale: ctx.locale ?? 'en',
        styles: [initialProps.styles, sheet.getStyleElement()],
      }
    } finally {
      sheet.seal()
    }
  }

  render() {
    return (
      <Html lang={this.props.locale}>
        <Head>
          <link rel="icon" href="/iconGreyewi.png" />
        </Head>
        <body>
          <Main />
          <NextScript />
          <div id="modal" />
        </body>
      </Html>
    )
  }
}
```

`asPath` сохраняет текущую страницу при смене языка: с `/cv` переключатель ведёт на `/ru/cv`, а не на корень.

```tsx
import React, { Fragment } from 'react'
import { useRouter } from 'next/router'
import { SwitcherContainer, LocaleLink, Divider } from './styles'

const LOCALES = [
  { code: 'en', label: 'EN' },
  { code: 'ru', label: 'RU' },
] as const

const LocaleSwitcher = () => {
  const { asPath, locale } = useRouter()

  return (
    <SwitcherContainer>
      {LOCALES.map(({ code, label }, index) => (
        <Fragment key={code}>
          {index > 0 && <Divider>|</Divider>}
          <LocaleLink href={asPath} locale={code} $active={locale === code}>
            {label}
          </LocaleLink>
        </Fragment>
      ))}
    </SwitcherContainer>
  )
}

export default LocaleSwitcher
```

```tsx
import React, {useState, memo, Fragment} from "react";
import {Addition, Expand, Point, Static, GoalPoint} from "./styles";
import type {RoadmapEntry} from '../../i18n/structure'
import type {RoadmapText} from '../../i18n/types'

interface StoryPointI {
  point: RoadmapEntry,
  text: RoadmapText,
  isOpenedPoint: boolean,
  handleExpanded: boolean
}

const StoryPoint = ({point, text, handleExpanded, isOpenedPoint}: StoryPointI) => {
    const [isExpanded, setExpanded] = useState<boolean>(false)
    const isExpand = isExpanded || (!handleExpanded && isOpenedPoint)

    return (
        <Point onClick={() => setExpanded(prev => !prev)} clickable={handleExpanded}>
            <Addition>{point.icon}</Addition>
            <Expand
                isExpand={isExpand}
                onClick={e => e.stopPropagation()}
                top={text.plotPosition ?? point.plotPosition}
            >
                {text.plot}
            </Expand>
            <Static>{point.date}</Static>
            <Expand
                isExpand={isExpand}
                onClick={e => e.stopPropagation()}
                isSlide
                top={text.goalsPosition ?? point.goalsPosition}
            >
                <span>
                    {text.goalsLabel}:{' '}
                    {text.goals.map((goal, index) => (
                        <Fragment key={goal.name}>
                            <GoalPoint>{goal.name}</GoalPoint>
                            {goal.note ? ` (${goal.note})` : ''}
                            {index < text.goals.length - 1 ? ', ' : ''}
                        </Fragment>
                    ))}
                </span>
            </Expand>
        </Point>
    )
}

export default memo(StoryPoint)
```

```tsx
import {Line, MapContainer} from './styles'
import {roadmapStructure} from '../../i18n/structure'
import {useTranslation} from '../../i18n/useTranslation'
import StoryPoint from './StoryPoint'
import useScrollPosition from './useScrollPosition'
import React, {useState, useEffect, useCallback, useRef} from "react"

const RoadMap = () => {
    const {roadmap} = useTranslation()
    const {current} = useRef<{
        roadMapWidth: number,
        bodyStyle: CSSStyleDeclaration | null
    }>({
        roadMapWidth: roadmapStructure.length * 700,
        bodyStyle: null
    })

    useEffect(() => {
        current.bodyStyle = window.document.body.style
    }, []) // empty deps — runs once on mount; current is a stable ref value

    const [scrollPosition, setScrollPosition] = useScrollPosition(0, 200)
    const [openedPointList, setOpenedPointList] = useState<string[]>([])

    useEffect(() => setOpenedPointList(prev => [...prev, roadmapStructure[scrollPosition].id]), [scrollPosition])
    useEffect(() => {
        return () => {
            if (current.bodyStyle) current.bodyStyle.overflow = "auto"
        }
    }, [])

    const handleScroll = useCallback((e: React.WheelEvent<HTMLDivElement>) => {
        const target = e.currentTarget
        const scrollLeft = target.scrollLeft
        const clientWidth = target.clientWidth

        setScrollPosition(e, Math.round(scrollLeft / (current.roadMapWidth - clientWidth) * (roadmapStructure.length -1)))

        target.scrollLeft = scrollLeft + e.deltaY
        if (!current.bodyStyle) return
        if (target.offsetWidth + scrollLeft >= target.scrollWidth) {
            current.bodyStyle.overflow = "auto"
        }
        if (target.offsetWidth + scrollLeft < target.scrollWidth) {
            current.bodyStyle.overflow = "hidden"
        }
    }, [setScrollPosition, current])

    const handleSetRoadMapFocus = useCallback(() => {
        if (typeof window === 'undefined' || !current.bodyStyle) return
        current.bodyStyle.overflow = window.scrollY === 0 ? "hidden" : "auto"
    }, [current])

    const handleSetRoadMapBlur = useCallback(() => {
        if (current.bodyStyle) current.bodyStyle.overflow = "auto"
    }, [current])

    return (
        <MapContainer
            onWheel={handleScroll}
            onMouseEnter={handleSetRoadMapFocus}
            onMouseLeave={handleSetRoadMapBlur}
        >
            <Line width={current.roadMapWidth}>
                {roadmapStructure.map((item) =>
                    <StoryPoint
                        point={item}
                        text={roadmap[item.id]}
                        key={item.id}
                        isOpenedPoint={openedPointList.includes(item.id)}
                        handleExpanded={false}
                    />)}
            </Line>
        </MapContainer>
    )
}

export default RoadMap
```
